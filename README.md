# E-Commerce Application (React)

This is a simple E-Commerce web application built using React. The project simulates a real-world online shopping experience with essential features like product listing and cart functionality.

## Features

* Product listing with dynamic data
* Search and category-based filtering
* Add to cart functionality
* Fully responsive design
* Reusable components

## Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

## What I Learned

* Managing state using React hooks
* Building reusable components
* Handling props and conditional rendering
* Creating responsive UI layouts
* Structuring scalable frontend applications
